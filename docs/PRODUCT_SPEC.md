# ReproLens 产品设计

## 产品目标

把一条模糊的 Web Bug 描述转化成开发者可以验证、共享和继续处理的工程资产：浏览器操作轨迹、跨设备截图、运行时证据、结构化结论和 Playwright 回归测试。

## 目标用户

- 前端开发者：缩短复现和补回归测试的时间。
- QA 工程师：自动采集标准化证据，减少重复操作。
- 开源维护者：快速判断 Issue 是否可复现。
- 独立开发者：在没有专职 QA 的情况下完成基础验证。

## V1 用户路径

1. 用户打开工作台。
2. 输入 URL、问题描述和期望结果。
3. 选择 Desktop、iPhone 13 或 Pixel 7。
4. 点击启动可视化复现。
5. 页面进入运行详情，实时展示 Agent 时间线。
6. 每个设备完成后出现截图与结构化发现。
7. 任务完成后展示结论、置信度、评分和回归测试。
8. 用户复制测试代码，或从历史记录重新打开结果。

## 页面设计

### 工作台

- 项目价值主视觉
- 累计运行、复现次数、平均评分、Provider 状态
- 任务输入表单
- 多设备选择器
- 最近运行列表

### 运行详情

- 复现结论、置信度、耗时、引擎、质量评分
- 模拟浏览器证据区和设备切换
- 实时 Agent 执行时间线
- 按严重程度展示的结构化发现
- 可复制的 Playwright 测试代码
- Console、Network、A11y 和设备统计

## V1 成功标准

- 新用户安装后 5 分钟内可以运行内置 Demo。
- 用户不需要阅读日志就能判断问题是否复现。
- 每个高优先级结论都有浏览器或运行时证据。
- 没有 DeepSeek Key 时，基础检测仍能运行。
- 生成测试不包含模型凭空发明的选择器。
- Windows 和 macOS/Linux 都有明确启动说明。

## Phase 2：修复验证闭环

### 用户路径

1. 用户打开一条已完成的复现任务，并将其作为不可变基线。
2. 输入修复后页面地址，系统复用原问题、期望结果、设备矩阵和 Agent 操作路径。
3. 每个设备完成重新扫描后，系统对不同尺寸的全页截图做白色画布归一化。
4. 本地像素引擎生成 Before、After、Pixel Diff，并计算变化比例。
5. 确定性规则对比质量分和去重后的问题根因，输出修复有效、发现回归、视觉变化或基本无变化。

### 成功标准

- 不依赖 AI Provider 也可以完成像素对比与修复结论。
- 同一验证任务同时保留运行时证据、结构化发现和视觉 Diff。
- 基线缺失、未完成或缺少目标设备截图时，API 返回明确的 4xx 错误。
- 内置 Demo 可以在本机完整演示故障版到修复版的闭环。
- 前端在桌面和移动尺寸下均可查看三联证据。

## 暂不实现

- 自动修改被测项目业务代码
- 未经确认自动创建 GitHub PR
- 登录态托管和团队权限
- 公网多租户执行
- Figma 设计稿同步
- 桌面应用自动化

这些能力会扩大安全边界和交付周期，应在第一版获得真实使用反馈后再实现。
